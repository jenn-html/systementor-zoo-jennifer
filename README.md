# Systementor Zoo Jennifer

A school project creating a website for a fictive zoo.

## 📋 Overview

This repository contains an HTML-based website for an imaginary zoo, built as a school project. The site showcases various web development concepts including structure, layout, and content organization. Perfect for learning web development with HTML.

## 🎓 Project Details

- **Type:** School Project
- **Purpose:** Creating a website for a fictional zoo
- **Language:** HTML
- **Learning Focus:** Web development fundamentals

## 🚀 Features

- Clean HTML structure
- Zoo-themed content and layout
- Well-organized project structure
- Easy to navigate and modify

## 🛠️ Getting Started

### Prerequisites
- A modern web browser
- A code editor (VS Code, Sublime Text, etc.)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/jenn-html/systementor-zoo-jennifer.git
cd systementor-zoo-jennifer
```

2. Open `index.html` in your web browser

## 📖 Usage

Browse through the zoo website to explore the different sections and learn how the HTML structure creates a functional web page.
